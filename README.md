# Capuchin Cooperation Study 1

Data and analysis code for a study testing whether capuchin monkeys (Sapajus spp.) are sensitive to absolute and relative payoffs when deciding whether to cooperate with a partner or work alone.

## How to run

Everything runs from `Study_1_Analysis.Rmd`. Open it in RStudio and run the chunks in order. The script sets its working directory to its own file location, so no paths need to be edited as long as the data files stay in the same folder as the .Rmd.

Running the script will:
1. Load and clean the raw data.
2. Split it into Experiment 1 and Experiment 2 subsets.
3. Run all statistical models reported in the manuscript.
4. Generate the figures.

## Data files

- `Study_1_Data_Cleaned.xlsx` — the full cleaned dataset, combining both experiments. This is the primary data file read by the script.
- `dyad_attributes.xlsx` — demographic and relationship data for each subject-partner dyad (e.g., rank, kinship, social closeness), also read directly by the script.
- `Exp_1_Data_Cleaned.xlsx` and `Exp_2_Data_Cleaned.xlsx` — generated automatically by the script when it splits the full dataset by experiment. These are outputs, not inputs, and do not need to be run or edited on their own.

## Figures

Figures are generated by the script and saved to the working directory, then moved into the `/Figures` folder.

## Videos

`/Videos` contains example video clips of trial sessions from the experiment.
